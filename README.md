# Student Attendance and Leave API

## Project Description

A FastAPI-based REST API for managing student records, attendance,
and leave requests.

## Features

- JWT authentication
- Role-based access control
- Student CRUD operations
- Resource ownership authorization
- Search and filtering
- Pagination
- Structured logging
- Error handling
- Safe transaction rollback
- Automated testing
- OpenAPI documentation

## Technology Stack

- Python
- FastAPI
- SQLAlchemy
- PostgreSQL
- Pydantic
- JWT
- Pytest
- Uvicorn
